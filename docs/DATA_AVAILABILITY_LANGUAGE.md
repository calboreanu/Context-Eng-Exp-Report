# Data-availability language

## Current public-release language

> Analysis code, rule contracts, aggregate outputs, a data dictionary, claim-to-evidence mappings, integrity receipts, and a generated fictional-source smoke test are available in the immutable Version 1.0.0 release at https://github.com/calboreanu/Context-Eng-Exp-Report/releases/tag/v1.0.0. Code and executable specifications are licensed under Apache-2.0; documentation and public aggregate evidence are licensed under CC BY 4.0. The release supports independent checking of the published aggregate arithmetic, traceability mappings, exact distributed bytes, and executable structure. Raw prompts, responses, exact timestamps, paths, conversation identifiers, balanced row derivatives, and candidate-linkage records are not distributed because they may contain confidential information or permit trajectory reconstruction. Authorized source-level verification may be considered under an appropriate controlled-access agreement.

Use the immutable release URL rather than a moving default-branch URL. The release notes record the downloadable archive digest.
